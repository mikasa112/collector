# 北向 IEC 104 子站（Server）配置说明

解析代码：`collector-core/src/config/north_iec104_conf.rs`
服务实现：`collector-core/src/dock/iec104/`，底层协议栈 `collector-iec60870::Slave`
示例点表：`config/北向/IEC104_SERVER.xlsx`

采集器在这里是 IEC 104 **子站（服务端）**：上级调度/主站来连接它，总召唤、接收突发上送，并下发遥控遥调。
数据来源是 DataCenter，所以既能转发下游设备的数据，也能转发 EMU 引擎（设备 id 为 `emu`）的数据。
与"采集器作主站"的 `iec104_config.md` 方向相反，两者互不影响。

## 启用（config.json 的 `program.north_iec104`）

```json
"north_iec104": {
  "enable": true,
  "host": "0.0.0.0",
  "port": 2404,
  "conf": "./config/北向/IEC104_SERVER.xlsx",
  "max_connections": 0,
  "multi_master": false,
  "select_timeout_ms": 30000,
  "require_select": false
}
```

| 字段 | 说明 |
|---|---|
| `enable` | 默认 `false`。 |
| `host` / `port` | 监听地址与端口，104 默认 `2404`。 |
| `conf` | 点表路径。文件打不开或没有 `iec104_server` sheet 时服务不会启动，日志里有错误。 |
| `max_connections` | 最大同时连接数，`0` 为库默认值。 |
| `multi_master` | `false`：只有一个激活连接收到突发上送（主备通道场景）；`true`：每个在线主站各自独立收到。 |
| `select_timeout_ms` | 两步命令从"选择"到"执行"的最长间隔，默认 30 秒。 |
| `require_select` | `true` 时执行命令前必须先选择，否则回否定确认；`false` 时允许直接执行。 |

APCI 参数固定为 k=12、w=8、t1=15 秒、t2=10 秒、t3=20 秒。支持多个 CA，由点表的 `ca` 列区分。

## 点表 Sheet 结构

只读取名为 `iec104_server` 的 sheet，第 1 行是表头，从第 2 行开始是数据。遥信、遥测、遥控、遥调都放在同一个 sheet，靠 `type` 列区分。

| 列号(0-based) | 表头 | 必填 | 说明 |
|---|---|---|---|
| 0 | ca | 必填 | 公共地址，`1~65534`。 |
| 1 | ioa | 必填 | 信息对象地址，`1~16777215`，十进制。 |
| 2 | type | 必填 | 见下表，不区分大小写。 |
| 3 | source | 必填 | 数据来源的 DataCenter 设备 id，如 `emu`、`bms-1`。 |
| 4 | point_id | 必填 | 该设备下的点位 id。遥控遥调的下发目标也是它。 |
| 5 | scale | 选填 | 缺省 `1`，不能为 `0`。仅遥测、遥调生效。 |
| 6 | offset | 选填 | 缺省 `0`。仅遥测、遥调生效。 |
| 7 | deadband | 选填 | 遥测死区（工程值绝对量），缺省 `0`：有变化就上送。 |
| 8 | timestamp | 选填 | 非 0 时上送带 CP56Time2a 时标的类型（`*_TB_1`/`*_TD_1`/`*_TE_1`/`*_TF_1`），用于 SOE。缺省不带时标。 |
| 9 | enable | 选填 | 缺省启用，填 `0` 禁用该行。 |
| 10 | name | 选填 | 点位名，仅用于日志。 |

同一份点表里，监视点（遥信遥测）的 `(ca, ioa)` 不能重复，控制点的 `(ca, ioa)` 也不能重复；控制点可以和监视点共用同一个地址。重复的行会被忽略并记录错误日志。同一个 DataCenter 点可以在不同 `(ca, ioa)` 下暴露多次。

### type 取值

| type | 含义 | 方向 | 对应 104 报文 |
|---|---|---|---|
| `yx` | 单点遥信 | 上送 | M_SP_NA_1 / M_SP_TB_1 |
| `yx_double` | 双点遥信（0 中间、1 分、2 合、3 不确定） | 上送 | M_DP_NA_1 / M_DP_TB_1 |
| `yc_short` | 短浮点遥测 | 上送 | M_ME_NC_1 / M_ME_TF_1 |
| `yc_scaled` | 标度化遥测（int16，超出范围按边界截断） | 上送 | M_ME_NB_1 / M_ME_TE_1 |
| `yc_normalized` | 归一化遥测（-1~1，超出按边界截断） | 上送 | M_ME_NA_1 / M_ME_TD_1 |
| `yk` | 单点遥控，下发 `U8(0/1)` | 接收 | C_SC_NA_1 |
| `yk_double` | 双点遥控，只接受分(1)/合(2)，下发 `U8(1/2)` | 接收 | C_DC_NA_1 |
| `yt_short` | 短浮点遥调，下发 `F64` | 接收 | C_SE_NC_1 |
| `yt_scaled` | 标度化遥调，下发 `F64` | 接收 | C_SE_NB_1 |
| `yt_normalized` | 归一化遥调，下发 `F64` | 接收 | C_SE_NA_1 |

### 量纲换算

与采集器作主站时的点表保持互逆：

- 上送：`上送值 = (工程值 - offset) / scale`
- 下发：`工程值 = 命令值 * scale + offset`

例：电压 `220.0`、`scale=0.1` 的标度化遥测上送 `2200`；收到标度化设点 `2200` 下发工程值 `220.0`。

## 行为说明

- **总召唤**：按请求的 CA 返回该 CA 下的全部监视点。设备数据还没到的点以"无效"品质上送，数据到达后自动恢复。
- **突发上送**：订阅每个来源设备，值变化（遥测超出死区）时以 COT=3 上送。服务启动时每个点会上送一次当前值。
- **通讯故障**：来源设备的通讯状态点（id `65535`，非 0 为故障）置位时，该设备下所有点品质置无效（IV），恢复后变回良好。
- **遥控遥调**：按 `(ca, ioa)` 找到控制点，换算后调用 `DataCenter::dispatch` 下发，成功回肯定确认（ACT_CON），失败回否定确认。以下情况回否定确认：
  - 未配置的 `(ca, ioa)`；命令类型与点类型不符；值非法（如双点遥控下发了中间态）；
  - 来源设备没有下行通道，或下发超时（3 秒）；
  - `require_select=true` 且执行前没有选择或选择已超时；
  - EMU 控制源为本地时，北向下发被拒绝（EMU 运行模式点位除外），与北向 Modbus 一致。
- **选择/执行**：选择阶段只校验和预置，不会下发；只有执行阶段才下发。
- **时钟同步**：收到后回确认，但不会修改本机系统时间。

## 限制

- 不支持步位置命令（C_RC_NA_1）、计数量召唤、分组召唤（只响应站总召唤）、TLS。
- 点表改动需要重启采集器生效。
